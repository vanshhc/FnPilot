# Governance

Vansh Chaudhari maintains FnPilot. MIT licensing for FnPilot-owned code was explicitly approved on 2026-10-28. Contributors retain ownership of their contributions and contribute under the project license; third-party terms remain attached to their actual dependencies and assets.

Maintainers review scope, safety contracts, platform claims and evidence. Public source readiness is independent of official binary readiness. The migration plan's hardware, signing and cutover gates require explicit receipts. No process changes should imply that unmeasured performance or unsupported capabilities passed.
