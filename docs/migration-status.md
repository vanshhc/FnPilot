# Migration implementation status

Rust/Tauri is the active desktop implementation. The standalone Swift app, command core, CLI and old packaging tools are removed. Native macOS integration is now Rust in `crates/fnpilot-platform/src/macos`. Only the retained WhisperKit speech decoder binding and its nonexecuting comparison executable remain in `native/macos`. New features belong in Rust/Tauri, enforced by an architecture boundary test. No installed app, legacy preferences or model cache was replaced or deleted.

Selected live Mac development paths now pass: physical Fn/voice (user confirmed), activation, literal typing, exact-label control, minimize/maximize/restore, cancellation recovery and GUI helper start/health/stop. The user-approved local Apple Development signer preserves all three macOS grants across changed native builds. See [Mac E2E evidence](validation/macos-e2e.md); remaining physical-key/stress and release qualification is explicit there.

Local implementation and builds do not establish all acceptance criteria. Windows hardware, official distribution signing and maintainer-reviewed publication/cutover decisions are external dependencies. The protected release workflow is implemented and fails closed without exact-revision acceptance receipts and credentials; it has not been run. No official release or source publication is claimed.

See [local verification](validation/local-checks.md), [development](development.md), [model setup](models.md), and [release procedure](releasing.md). Parser-only fixture routing remains 78/100 expected corpus results without model fallback, alongside exact 112-case legacy parser parity; model-dependent corpus expectations do not become deterministic-parser passes.
